# Complete UI audit — defects, root causes, fixes (14 Nov 2026)

Method: source inspection of the shared layer (`web/app/app.css`, `js/core.js`, `js/main.js`) and every page module, plus the measured audit (`scripts/responsive_audit.py`, 49 routes × 17 viewports, before and after). Screenshots: `docs/visual-regression/` (before/after crops) and `docs/responsive-screenshots/{before,final}/<route>/<viewport>.jpg`.

Shared components inspected with no defect found: page header/crumbs, KPI cards (wrap to 2 columns on phones, 1 below 360 px), cards and tiles, `select`/`slider` helpers, empty and error states (`.empty`, `.err`, `.loading` all content-sized), 404 page. There are no modal dialogs in the product; the only overlay is the mobile drawer.

Global selectors checked for leakage: `button` (styled once; `.chip`, `.ng>button` and zoom buttons override explicitly), `svg` (`max-width:100%` except the matrix scroller), `section/article` (unstyled), `.card` (content-driven height; no fixed heights anywhere in the CSS except the atlas box, which is an aspect-ratio viewport).
